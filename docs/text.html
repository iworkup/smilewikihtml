Стандартное оформление текста

Параграфы, перенос строки и стандартные HTML-элементы оформления текста.

Это обычный параграф текста.

Это следующий параграф — отдельная мысль.

Первая строка параграфа.
Вторая строка после принудительного переноса.

Можно выделить важный фрагмент текста.

Этот фрагмент удалён из документа.

Эти сведения больше не актуальны.

Этот фрагмент добавлен в документ.

Это слово с подчёркнутой аннотацией.

Это примечание мелким шрифтом.

Это важный текст, выделенный полужирным.

Это текст с логическим ударением, выделенный курсивом.

HTML 
<p>Это обычный параграф текста.</p>
<p>Это следующий параграф — отдельная мысль.</p>
<p>Первая строка параграфа.<br>Вторая строка после принудительного переноса.</p>
<p>Можно <mark>выделить</mark> важный фрагмент текста.</p>
<p><del>Этот фрагмент удалён из документа.</del></p>
<p><s>Эти сведения больше не актуальны.</s></p>
<p><ins>Этот фрагмент добавлен в документ.</ins></p>
<p><u>Это слово с подчёркнутой аннотацией.</u></p>
<p><small>Это примечание мелким шрифтом.</small></p>
<p><strong>Это важный текст, выделенный полужирным.</strong></p>
<p><em>Это текст с логическим ударением, выделенный курсивом.</em></p>

Тег <p> создаёт отдельный параграф, а <br> переносит строку внутри него. Используйте смысловые теги по назначению: <del> и <ins> отмечают изменения, <strong> — важность, <em> — логическое ударение.
