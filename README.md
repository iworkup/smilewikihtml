# SmileWiki HTML

Стартовый HTML-шаблон wiki-проектов на готовых компонентах Bootstrap v6, установленном через npm. Используется **6.0.0-alpha.1**: это предварительный выпуск, версия зафиксирована в package-lock.json. Собственные стили и изменения дизайна требуют отдельного разрешения.

## Запуск

Нужен Node.js 22.12+ (либо 24 LTS) и npm.

```sh
npm ci
npm run dev
```

Vite слушает все сетевые интерфейсы. HTML автоматически перезагружается при сохранении, изменения импортируемых CSS/JS обновляются через HMR. Отдельный LiveReload-сервер не нужен.

Постоянные адреса разработки:

- На этом компьютере: http://localhost:5173/smilewikihtml/
- С другого устройства в той же сети: http://MacBook-Pro-Igor.local:5173/smilewikihtml/

Имя macOS через mDNS сохраняется при смене IP. На другом устройстве должна поддерживаться mDNS/Bonjour; устройства должны быть в одной локальной сети без изоляции клиентов, а брандмауэр должен разрешать входящие подключения Node.js. Имя компьютера менять нельзя, иначе сетевой адрес изменится. Для устройств без mDNS потребуется постоянная DHCP-резервация на роутере. Порт фиксирован: при занятости запуск завершится ошибкой, адрес сам не поменяется.

## Структура

- `smilewikihtml/` — исходный HTML, JS и будущая разрешённая кастомизация.
- `docs/` — результат сборки для GitHub Pages; вручную не редактировать.
- `node_modules/` — npm-зависимости, исключены из Git.
- `.github/workflows/deploy.yml` — сборка и публикация при пуше в `main`, а также ручной запуск.

В настройках репозитория Pages используется источник **GitHub Actions**. CI выполняет `npm ci`, собирает `docs/` и публикует артефакт. Для публикации достаточно пуша в `main`.

Правила дальнейшей работы: [AGENTS.md](AGENTS.md).

## AI-инструкции Bootstrap

Из [официальной страницы](https://getbootstrap.com/docs/6.0/getting-started/ai/) установлены все 11 скиллов в `~/.codex/skills/` и сохранены в `.agents/skills/` для репозитория и gigacode. Codex автоматически увидит установленные скиллы со следующего сообщения. Индекс документации — `.agents/bootstrap/llms.txt`; полный текст доступен по https://getbootstrap.com/llms-full.txt и загружается только при необходимости.

Скиллы взяты из `twbs/bootstrap`, ветка `main`, 25 октября 2026, commit `2bb544eb426e9b1e019c2a98798e0002b8a41d35`. Для конкретной разметки проверять документацию версии 6.0.0-alpha.1. Код скиллов — MIT, документация Bootstrap — CC BY 3.0.

В `.gigacode/settings.json` подключён Chrome DevTools MCP с изолированным профилем. Для его первого запуска нужны Chrome, Node.js и доступ к npm. Проверки можно поручать gigacode: открыть адрес, проверить desktop/mobile, интерактивность, консоль и сеть, затем вернуть краткий отчёт. Не отключать проверки, если MCP недоступен: выполнить их через Chrome MCP в Codex.
